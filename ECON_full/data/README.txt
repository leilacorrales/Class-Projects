Currency Crisis Emerging-Market Panel

Study period: 1970-2016. The HBS source file ends in 2016, so later years are not available from this outcome source.

Outcome: HBS Global Crises Data, Currency Crises field. Raw codes are retained in currency_crisis_raw; codes 1 and 2 are coded as currency_crisis=1, code 0 as 0.

Sample: HBS countries not in the IMF WEO advanced-economy list. IMF WEO Groups and Aggregates: https://data.imf.org/en/Datasets/WEO/Groups-and-Aggregates-October-2024

Predictors: World Bank WDI API indicators. Source: https://data.worldbank.org/

Important limitation: the IMF WEO download endpoint was blocked during this run, so the country sample was implemented as the complement of the IMF advanced-economy list using the official IMF Groups and Aggregates page. Review country names and codes before modeling.

No lagged variables are included.
